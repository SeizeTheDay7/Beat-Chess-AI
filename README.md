약간의 어드밴티지를 갖고 AI와 체스를 하는 3D 공포 게임. Unity 1인 개발입니다.

> 체스 로직 구현

- 상속을 적절하게 활용하여 체스 기물들의 이동 로직을 재사용성 높게 작성
- 체크메이트 되는 곳은 이동할 수 없도록 검증하기 위해 가상으로 움직여보는 로직 구현
- 상태 패턴을 사용하여 플레이어와 AI의 턴 배분


> 로봇 팔 IK 애니메이션 구현

- FABRIK 등의 기존 알고리즘이 원하는 절도있는 움직임을 보여주지 못할 것 같아서 직접 구현
- 문제를 수식으로 정리한 다음, 3D 모델을 직접 편집도 하며 로봇 팔이 체스를 놓는 움직임 구현
- Command 패턴을 활용하여 로봇 팔 애니메이션의 순차적 실행 보장
